1. RIDUZIONE DI UNA MATRICE NELLA FORMA A SCALINI
-------------------------------------------------

Con operazioni sulle righe **di prima e seconda specie** ogni matrice si può
portare in una forma più leggibile, **detta a scalini**, da cui **il rango si vede**
a colpo d'occhio.

Sia A di tipo (m, n) su K. A è a scalini per righe se è nulla oppure
è fatta così: le prime r righe sono non nulle (1 ≤ r ≤ m), le restanti
sono nulle, e in ogni riga non nulla i c'è un primo elemento diverso da
zero di colonna jᵢ, con j₁ < j₂ < ... < jᵣ. Prima **di quel pivot** la riga
ha solo zeri: a_{i,jᵢ} ≠ 0 e a_{i,j} = 0 per j < jᵢ.

Il rango è allora r: è il numero di gradini da scendere dalla prima riga
per arrivare a una riga nulla, oppure all'ultima riga quando r = m. Le
colonne j₁, ..., jᵣ **si dicono caratteristiche** e gli scalari a_{i,jᵢ}
sono i pivot.

Esempio nuovo: la matrice

2  1  0
0  0  3
0  0  0

è a scalini con r = 2, colonne caratteristiche 1 e 3, pivot (2, 3).
Invece

0  4  1
0  0  0
5  0  0

non è a scalini: la terza riga riparte da colonna 1, rompendo la crescita
j₁ < j₂.

Altro esempio nuovo: la diagonale D(3, 0, 0) è a scalini perché i non
nulli vengono prima degli zeri (i = 1, rango 1); D(0, 3, 5) non lo è,
perché inizia con uno zero seguito da non nulli.

Risultato principale: ogni A si riduce a scalini con un numero finito di
operazioni di prima e seconda specie sulle righe. L'idea è induttiva: si
individua la prima colonna non tutta nulla j₁ e una riga i₁ dove
l'elemento è non zero, si azzera il resto della colonna con operazioni di
prima specie, si porta quella riga in testa con uno scambio e si ripete
sulla sottomatrice senza la prima riga.

Un caso particolare utile è quello delle matrici legate a una permutazione.
Dati k₁, ..., kₙ ∈ K e una permutazione σ di Iₙ, la matrice
D_σ(k₁, ..., kₙ) ha in riga i solo zeri tranne kᵢ in colonna
σ(i): la riga i è kᵢ·e_{σ(i)}. In colonna j c'è solo k_{σ⁻¹(j)}
in riga σ⁻¹(j).

Esempio nuovo: con n = 3, σ(1) = 2, σ(2) = 3, σ(3) = 1 e terna
(2, -1, 5) si ottiene

0  2  0
0  0 -1
5  0  0

le cui colonne sono (5·e₃, 2·e₁, -1·e₂).

Conseguenze:

- ogni D_σ(k₁, ..., kₙ) è completamente ridotta e il suo rango è il
  numero di kᵢ non nulli; in particolare una **matrice di permutazione**
  D_σ(1, ..., 1) ha rango massimo n;
- una quadrata di rango massimo si porta con sole operazioni di prima
  specie sulle righe a una D_σ con tutti i kᵢ ≠ 0, e poi in diagonale
  con scambi sulle colonne;
- una (m, n) con m ≤ n (risp. n ≤ m) si porta con operazioni su righe
  e colonne alla scrittura a blocchi (D  0) (risp. colonna con D sopra
  e zeri sotto), dove D è diagonale.

Errore tipico: credere che a scalini significhi diagonale o triangolare
superiore con pivot in 1, 2, 3. Le colonne caratteristiche possono saltare
posti (es. 2 e 4) e i pivot possono essere qualsiasi scalare non nullo,
non necessariamente 1.

2. IL METODO DI ELIMINAZIONE DI GAUSS PER LA SOLUZIONE DI SISTEMI LINEARI
------------------------------------------------------------

Portare la **matrice completa a scalini** equivale a sostituire il sistema con
uno equivalente più facile da discutere e risolvere.

Dato un sistema A non nullo di m equazioni in n incognite, le
operazioni elementari sulle equazioni producono **un sistema equivalente** A'
con le stesse soluzioni. Si trasformi la completa in forma a scalini. Si
hanno due casi:

- caso compatibile con r equazioni effettive:

  a_{1,j₁}·x_{j₁} + ... + a_{1,n}·xₙ = c₁

  a_{2,j₂}·x_{j₂} + ... + a_{2,n}·xₙ = c₂

  ...

  a_{r,jᵣ}·x_{jᵣ} + ... + a_{r,n}·xₙ = cᵣ

  con j₁ < ... < jᵣ e pivot non nulli;

- caso incompatibile: come sopra per le prime r-1 righe, più una riga
  0 = cᵣ con cᵣ ≠ 0.

In entrambi i casi la completa di A' (e quindi di A) ha rango r. Nel
primo caso anche l'incompleta ha rango r: i sistemi sono compatibili e
ridotti. Nel secondo l'incompleta ha rango r-1: completa e incompleta
differiscono e non c'è soluzione.

Se si è nel caso compatibile, le colonne j₁, ..., jᵣ sono un massimo di
**colonne indipendenti** dell'incompleta. Le incognite corrispondenti si
ricavano dalle altre, **dette libere**:

x_{jᵢ} = [cᵢ - (a_{i,j_{r+1}}·x_{j_{r+1}} + ... + a_{i,jₙ}·x_{jₙ}})] / a_{i,jᵢ}

dove j_{r+1}, ..., jₙ sono gli indici fuori dai pivot. Se r = n la
soluzione è unica; se r < n è **parametrica con n-r parametri**.

Errore tipico: leggere la compatibilità solo dalla forma senza confrontare
i ranghi di completa e incompleta, oppure assegnare i parametri alle
incognite pivot invece che a quelle libere. Altro errore: fermarsi a
0 = 0 credendo sia incompatibilità; 0 = 0 si scarta, è 0 = cᵣ ≠ 0
a segnalare impossibilità.

3. ESEMPI
---------

Primo sistema nuovo, **con soluzione unica**. Si risolva su Q:

x + y + z = 6
x - y + z = 2
x + y - z = 0

La completa è

1  1  1  6
1 -1  1  2
1  1 -1  0

Azzeriamo la prima colonna sotto la riga 1 con (2, 1; -1) e
(3, 1; -1):

1  1  1  6
0 -2  0 -4
0  0 -2 -6

È già a scalini con colonne caratteristiche 1, 2, 3 e pivot
(1, -2, -2). Il sistema equivalente è

x + y + z = 6
-2y = -4
-2z = -6

da cui dal basso z = 3, y = 2, x = 6 - 2 - 3 = 1. Soluzione unica
(1, 2, 3). Completa e incompleta hanno rango 3 = n.

Secondo sistema nuovo, con infinite soluzioni. Si risolva:

x + 2y + z = 4
2x + y + z = 5
3x + 3y + 2z = 9

La completa è

1  2  1  4
2  1  1  5
3  3  2  9

Con (2, 1; -2) e (3, 1; -3):

1  2  1  4
0 -3 -1 -3
0 -3 -1 -3

Con (3, 2; -1):

1  2  1  4
0 -3 -1 -3
0  0  0  0

È a scalini con r = 2, colonne caratteristiche 1, 2, pivot (1, -3).
Il sistema è

x + 2y + z = 4
-3y - z = -3
0 = 0

La riga nulla si scarta. Restano due equazioni in tre incognite: una
libera. Ponendo y = t si ha z = 3 - 3t e x = 4 - 2t - z = 1 + t.
Soluzioni (1+t, t, 3-3t) al variare di t. Ad esempio per t = 0 si ha
(1, 0, 3).

Errore tipico in questi calcoli: dividere una riga per il pivot senza
dividere anche il termine noto, o dimenticare di applicare lo scambio di
righe quando la prima colonna utile parte più sotto.

Concetti chiave da ricordare
----------------------------

- A scalini: r righe non nulle con pivot in colonne crescenti
  j₁ < ... < jᵣ, zeri prima di ogni pivot, resto nullo; rk = r.
- Colonne caratteristiche e pivot individuano il massimo indipendente.
- Ogni matrice si porta a scalini con operazioni di prima e seconda specie
  sulle righe.
- D_σ(k₁, ..., kₙ) ha righe kᵢ·e_{σ(i)}; rango uguale al numero di kᵢ
  non nulli.
- Portando la completa a scalini, 0 = cᵣ ≠ 0 significa incompatibile;
  0 = 0 si elimina.
- Nel caso compatibile le incognite pivot si esprimono con quelle libere;
  n-r parametri se r < n, unica se r = n.

a) sistema compatibile con 1 parametro · b) sistema incompatibile ·

6. Un sistema di 3 equazioni in 4 incognite ridotto a scalini con
r = 2 compatibile ha soluzioni dipendenti da:
a) 0 parametri · b) 1 parametro · c) 2 parametri · d) 4 parametri

Soluzioni ragionate

1 — b. Pivot in colonne 1 poi 3, crescenti, con ultima riga nulla.
La a) riparte da colonna 1 in terza riga; la c) ha pivot 1 poi 1
non crescente; la d) ha pivot 3 poi 2 decrescente.

2 — b. Il rango conta i gradini, non l'indice dell'ultima colonna; le
colonne caratteristiche sono proprio 2, 5. La a) confonde indice e rango,
la c) conta un gradino in più, la d) fraintende la definizione che ammette
salti.

3 — a. Riga 1: 4 in colonna 3; riga 2: 0 in colonna 1;
riga 3: 6 in colonna 2. Le altre dispongono i valori in posti errati.

4 — c. Due coefficienti non nulli (4, 6) e uno nullo danno rango 2.
La a) conta anche lo zero, la b) ne conta uno solo, la d) li azzera tutti.

5 — b. 0 = 5 ≠ 0 alza il rango della completa sopra quello
dell'incompleta: nessuna soluzione. La a) e la c) presuppongono
compatibilità, la d) confonde con 0 = 0.

6 — c. Parametri liberi n-r = 4-2 = 2. La a) varrebbe se r = n, la
b) se n-r = 1, la d) se nessuna equazione vincolasse.
