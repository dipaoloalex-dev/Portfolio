1. PARTE I
----------

Esercizi di base su simmetria, trasposta e prodotti semplici, qui riproposti
con numeri diversi dall'originale e con il metodo in evidenza.

Simmetria parametrica, esempio nuovo: sia
M = [[0, 2, p], [2, 1, q], [5, -1, 0]]. M **è simmetrica se p = 5** e
q = -1; non può mai **essere antisimmetrica perché** la diagonale contiene
1 ≠ 0. In generale una quadrata è simmetrica se a_{ij} = a_{ji},
antisimmetrica se a_{ij} = -a_{ji} con diagonale nulla. Una rettangolare
non è né simmetrica né antisimmetrica.

**Somma con la trasposta**, esempio nuovo: sia A = [[1, 3, 2], [0, 2, -1], [4, 0, 1]].
Allora Aᵀ = [[1, 0, 4], [3, 2, 0], [2, -1, 1]] e
B = A + Aᵀ = [[2, 3, 6], [3, 4, -1], [6, -1, 2]] **è simmetrica,**
C = A - Aᵀ = [[0, 3, -2], [-3, 0, -1], [2, 1, 0]] **è antisimmetrica.**
In generale Bᵀ = B e Cᵀ = -C per (A ± Aᵀ)ᵀ = Aᵀ ± A, e vale
B + C = 2A.

Fatti utili: simmetrica più antisimmetrica dà solo la nulla (A = Aᵀ = -Aᵀ
implica 2A = 0); combinazioni di simmetriche restano simmetriche e di
antisimmetriche restano antisimmetriche perché (αS)ᵀ = αSᵀ.

Diagonali, esempio nuovo: D₁ = diag(2, -1, 3), D₂ = diag(4, 5, -2).
Il **prodotto è diagonale con prodotti voce a voce**:
D₁D₂ = diag(8, -5, -6), cioè (D){ij} = aᵢbᵢδ{ij}.

Permutabilità da combinazione, esempio nuovo: se 2A + 3B = 5I con
coefficienti non nulli, **moltiplicando a sinistra e a destra per A** e
sottraendo si ottiene 3(AB - BA) = 0, quindi [A, B] = 0.

Errore tipico: imporre simmetria senza controllare la diagonale per
l'antisimmetria, o pensare che A + Aᵀ possa non essere simmetrica.

2. PARTE II
-----------

Decomposizione, indipendenza e idempotenti, con valori nuovi.

Ogni quadrata si scrive **in un solo modo come A = S + E** con S simmetrica
ed E antisimmetrica: basta S = (A + Aᵀ)/2 ed E = (A - Aᵀ)/2.
L'unicità segue dal punto precedente: se S₁ + E₁ = S₂ + E₂ allora
S₂ - S₁ = E₁ - E₂ è insieme simmetrica e antisimmetrica, quindi nulla.

Indipendenza, esempio nuovo: con c₁, c₂, c₃, c₄ ≠ 0, le
[[c₁, 0], [0, 0]], [[0, c₂], [0, 0]], [[0, 0], [c₃, 0]],
[[0, 0], [0, c₄]] **sono indipendenti perché**
α₁c₁ = α₂c₂ = α₃c₃ = α₄c₄ = 0 implica ogni αᵢ = 0. Analoga
triangolazione dà l'indipendenza di famiglie a scala come
[[h₁, h₂], [h₃, h₄]], [[h₁, h₂], [h₃, 0]], [[h₁, h₂], [0, 0]],
[[h₁, 0], [0, 0]], da cui si ricava a cascata α₁ = 0, poi α₂ = 0, ecc.

Idempotenti (A² = A), fatti nuovi con stessa idea ma senza copiare i conti:

- **se A è idempotente lo è I - A**, perché
  (I - A)² = I + A² - 2A = I - A;
- lo è Aᵀ, perché (Aᵀ)² = (A²)ᵀ = Aᵀ;
- idempotente e antisimmetrica dà solo 0, perché A = A² = (-A)² = -A;
- se A, B idempotenti commutano, anche AB è idempotente:
  (AB)² = ABAB = AABB = AB.

Errore tipico: usare (A + B)² = A² + B² senza commutatività, o credere che
la trasposta rompa l'idempotenza.

3. PARTE III
------------

Problemi più articolati, riscritti con passaggi propri.

Per A, B simmetriche, AB è simmetrica **se e solo se commutano**:
(AB)ᵀ = BᵀAᵀ = BA, uguale ad AB solo se BA = AB.

Per ogni A di tipo (m, n), AAᵀ di tipo (m, m) e AᵀA di tipo
(n, n) sono definite e simmetriche, perché **(AAᵀ)ᵀ = AAᵀ**.

Permutabilità 2 × 2, esempio nuovo: siano A = [[a, 0], [b, a]] e
B = [[x, 0], [y, y]] con notazione diversa per i conti ma stessa struttura
dell'idea originale. Allora AB - BA = 0 equivale a b(x - y) = 0: o
b = 0 qualsiasi, o x = y qualsiasi.

Sistema impossibile, esempio di metodo: X² = 0, Y² = 0, X - Y = 2I
non ha soluzioni. Da X(X - Y) = 2X e (X - Y)X = 2X segue XY = YX,
quindi 0 = X² - Y² = (X - Y)(X + Y) = 2(X + Y), cioè X = -Y e 2X = 2I,
assurdo perché darebbe X² = I ≠ 0.

Insieme E = {A : A, Aᵀ dipendenti} coincide con simmetriche o
antisimmetriche: da A = αAᵀ segue Aᵀ = αA, quindi A = α²A, cioè
A = 0 oppure α = ±1.

Idempotenti 2 × 2: da [[x, y], [z, w]]² = [[x, y], [z, w]] si ottiene
x² + yz = x, (x + w)y = y, (x + w)z = z, yz + w² = w. Se y ≠ 0 o
z ≠ 0 allora x + w = 1 e xw - yz = 0; se y = z = 0 allora
x, w ∈ {0, 1}.

Errore tipico: fattorizzare X² - Y² = (X - Y)(X + Y) senza aver provato che
X e Y commutano, passaggio lecito solo dopo la prima deduzione.

Concetti chiave da ricordare
----------------------------

- A + Aᵀ simmetrica, A - Aᵀ antisimmetrica; B + C = 2A.
- Simmetrica e antisimmetrica insieme danno solo la nulla.
- Diagonali si moltiplicano voce a voce; αA + βB = γI con β ≠ 0 implica
  permutabilità.
- A = (A + Aᵀ)/2 + (A - Aᵀ)/2 è l'unica decomposizione simmetrica più
  antisimmetrica.
- I - A e Aᵀ ereditano l'idempotenza; AB idempotente se i fattori
  idempotenti commutano.
- AB di simmetriche è simmetrica se e solo se commutano; AAᵀ e AᵀA
  sempre simmetriche.
- Il sistema X² = Y² = 0, X - Y = 2I è impossibile.

1. Se M = [[0, 1, 5], [1, 0, -2], [5, -2, 7]], allora:
a) è simmetrica · b) è antisimmetrica · c) è sia simmetrica che

2. Per A = [[1, 2], [3, 4]], la parte simmetrica (A + Aᵀ)/2 è:
a) [[1, 2.5], [2.5, 4]] · b) [[0, -0.5], [0.5, 0]] · c) [[2, 5], [5, 8]] ·
d) [[1, 3], [2, 4]]

3. Con D₁ = diag(3, -2) e D₂ = diag(-1, 4) il prodotto è:
a) diag(-3, 8) · b) diag(2, 2) · c) [[-3, 0], [0, -8]] ·
d) non definito

4. Se A² = A, allora (I - A)² vale:
a) I + A · b) I - A · c) I · d) 0

5. Se A, B simmetriche e AB è simmetrica, allora:
a) AB = -BA sempre · b) AB = BA · c) A = B · d) det nullo

6. Il sistema X² = 0, X - Y = 2I con anche Y² = 0:
a) ha sempre la soluzione X = I, Y = -I · b) è impossibile ·
c) ha infinite soluzioni · d) dipende da n

Soluzioni ragionate

1 — a. Mᵀ = M voce a voce; la diagonale non nulla esclude
l'antisimmetria, quindi non la c). La d) è falsa perché è 3 × 3.

2 — a. Media con la trasposta: [[1, (2+3)/2], [(2+3)/2, 4]]. La b) è la
parte antisimmetrica, la c) è la somma non dimezzata, la d) è Aᵀ.

3 — c. Prodotto voce a voce 3·(-1) = -3, (-2)·4 = -8. La a) sbaglia
il secondo segno, la b) somma invece di moltiplicare, la d) nega un
prodotto tra diagonali dello stesso ordine.

4 — b. (I - A)² = I - 2A + A² = I - A. La a) sbaglia segno, la c)
dimentica -A, la d) varrebbe solo per casi banali.

5 — b. (AB)ᵀ = BA deve coincidere con AB. La a) darebbe
antisimmetria, la c) è sufficiente ma non necessaria, la d) è irrilevante.

6 — b. Come mostrato porta a X = I contro X² = 0. La a) non verifica
la prima equazione, c) e d) ignorano la contraddizione logica valida per
ogni n.
